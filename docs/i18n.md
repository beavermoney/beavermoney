# Interface languages

Beaver Money uses Lingui with English (`en`) as the source language and Simplified Chinese (`zh-CN`) as the first target. Choose **Language** on the login screen or in **Settings → General**. The choice is saved on the current device. On first use, supported browser language preferences are used; unsupported languages fall back to English. Traditional Chinese is not treated as Simplified Chinese.

Interface language is separate from the household's region setting, which continues to control monetary number formatting. Switching languages does not alter account names, descriptions, categories, amounts, currency codes, GraphQL enum values, or ISO date keys. Dates in the interface and Astryx controls follow the interface language. Raw server error details and user-authored content are not machine-translated at runtime.

## Adding or updating copy

Use `Trans` from `@lingui/react/macro` for JSX and `const { t } = useLingui()` from the same module for strings inside components. Use complete messages with interpolation; do not concatenate English sentence fragments or append `s` for plurals. Use Lingui's plural macro inside `t({ message: plural(...) })` for string-valued plural messages.

Keep message descriptors in shared static metadata (`msg` from `@lingui/core/macro`) and translate them during rendering with `i18n._()`. Never translate an enum value or a field used to identify a transaction category. Construct validation schemas inside components so their messages follow the active language. Explicit React memoization dependencies must include the translation function when used.

From `web/`:

```sh
pnpm i18n:extract
# Review and translate new messages in src/locales/zh-CN/messages.po.
pnpm i18n:check
pnpm test
pnpm build
```

Commit both PO catalogs. Source references are included without line numbers to keep diffs readable. Vite compiles the PO files; CLI-generated `messages.js` files are ignored. The strict check extracts current messages, removes obsolete ones, and rejects catalog drift, missing translations, or malformed messages. Both the test and production build commands run this check, including in CI.

AI can draft catalog translations, but review interpolation variables, terminology, plurals, accessibility labels, and mobile layout before committing. Translation does not call a hosted AI service or send financial data to one.

## Chinese terminology

| English | Simplified Chinese |
| --- | --- |
| Household | 家庭 |
| Account | 账户 |
| Transaction | 交易 |
| Entry | 分录 |
| Income / Expense | 收入 / 支出 |
| Transfer / Move investments | 转账 / 转移投资 |
| Investment lot | 投资批次 |
| Shares | 股数 (label), 股 (unit) |
| Net worth | 净资产 |
| Liability | 负债 |
| Snapshot | 快照 |

Keep product names, ticker symbols, currency codes, and registered account abbreviations such as TFSA and RRSP intact.
